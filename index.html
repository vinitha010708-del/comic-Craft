# ComicCraft - AI Comic Story Creator An AI tool that turns simple prompts into full comic stories with images + PDF export. Tech Stack: FastAPI + Gemini 1.5 Pro + Stable Diffusion + FPDF Team: Pavithra ## How it works 1. User gives prompt like "A brave fox exploring an enchanted forest" 2. Gemini generates story 3. Stable Diffusion generates images 4. Layout Builder + PDF Exporter creates comic book
